🏠 SafeZone — Check Your Community
Live site: safe-zones.org

SafeZone is a neighborhood-safety web app that helps teens and families understand their surroundings, especially in unfamiliar places. Enter a US ZIP code and SafeZone checks official public sex-offender registries for that area, so you can plan safer routes and make informed decisions.

Built by Unaysah Ron. 
Why SafeZone?
The idea came from traveling alone to New York for the first time and realizing there was no quick, teen-friendly way to tell whether an unfamiliar neighborhood was safe. Registry data is public under Megan's Law, but it's scattered across government sites that are hard to use on a phone. SafeZone makes that information simple, visual, and fast.

Features
ZIP code lookup: Enter any US ZIP code to check for registered offenders in that area.

Official sources only: SafeZone queries official public registries directly. Where a jurisdiction has no public data source, it links you to the official registry instead of showing a guess.

Safety resources for teens:
NSOPW: the National Sex Offender Public Website, for official nationwide registry searches
RAINN: confidential support for survivors of sexual violence
988 Suicide & Crisis Lifeline: call or text 988, any time
Tips on sharing your live location, saving emergency numbers, and finding safe public places
Mobile-friendly: Check an area on the go.
Privacy-first: No accounts and no personal data collected from users.

How to use it
Go to safe-zones.org.
Enter the ZIP code of where you're going (a hotel, campus, or friend's house).
Click Check My Area.
Review the results, or follow the link to the official registry for your jurisdiction.
Visit the resources section for safety tips and support links.

Tech stack
Frontend: HTML, CSS, JavaScript
Backend/data: Python
Data sources: Official public sex-offender registries (Megan's Law data). When a licensed provider is enabled, the ZIP code is sent to that provider for lookup.
Development: Developed using Python for the backend, HTML, CSS, and JavaScript for the frontend, along with AI-assisted development tools. All design, data, and safety decisions were made by the developer.

Responsible use
Registry records exist for personal safety awareness only. Using registry information to harass, threaten, or harm anyone is a crime. Records may be incomplete or out of date, so always verify against the official source before acting on them.
